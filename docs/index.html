Features

Built for documents you can't send to the cloud

Everything runs on one laptop with open-source models. No paid APIs, no data leaving the machine.

📎

Every sentence cited

Click a citation to read the exact passage, file, page and section. Citations are checked in code, so a source can't be invented.

🔒

Permission-aware search

Users only search the collections they belong to. The filter runs before the model sees anything, so nothing leaks.

🙅

Refuses instead of guessing

When the documents don't contain the answer, it says "I could not find sufficient evidence", not something made up.

🛡️

Injection quarantine

Uploaded text that tries to instruct the AI is caught by a pattern check and an LLM classifier, and never stored.

🤖

Verified agent reports

Agents plan, research and write claims; a verifier checks each one against the exact sentence it quotes.

✅

Human approval

Nothing is final until a second person approves. The requester can't approve their own report.

How it works

From upload to cited answer

Upload

PDF, Word or text. Text is extracted, cleaned and checked for attacks.

Index

Split into sections and embedded with nomic-embed-text into PostgreSQL + pgvector.

Retrieve

Only passages the user may read, close enough to the question to count.

Answer

qwen3:8b writes from the evidence only; citations are validated in code.
